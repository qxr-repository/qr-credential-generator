How it works / reader setup
  • QR content = facility × 65,536 + card, written as a plain decimal number (AxTraxPro "Simple text" QR type). Example: facility 100, card 12345 → 6565945.
  • 26-bit: facility 0–255, card 0–65,535. 34-bit: facility 0–65,535, card 0–65,535. The reader adds the parity bits.
  • Reader DIP switches: DIP 1 OFF + DIP 2 OFF = 26-bit; DIP 1 ON + DIP 2 OFF = 34-bit. Power-cycle the reader after changing them.
  • AY-x30QR wiring is non-standard: blue-white = D1, green-white = D0, white = Card Present (not D1).
  • Enroll the same facility code + card number in Qumulex / AxTraxPro. The CSV export lists them.
  • Recommended size about 3 × 3 cm; scan distance 5–10 cm.
  • KONE (Settings → Advanced): the same number as 8-digit lowercase hex, for KONE elevator readers. Example: 6565945 → 00643039.
